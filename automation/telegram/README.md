# Socialora Telegram otomasyonu

Kanal yayını, grup asistanı ve büyüme raporları yerel Windows n8n üzerinde çalışır. Akış tanımları [n8n](n8n) dizinindedir. [Yayın kuyruğunu](content.json) yayın akışı ve Socialora Kontrol Merkezi kullanır.

Akışların etkinliğini ve son çalıştırmalarını [Socialora Kontrol Merkezi](http://127.0.0.1:5678/workflow/socialoraCockpit01) üzerinden kontrol edin.

Android Termux yayıncısı, kurulum arşivi ve telefondan GitHub Issue #2'ye gönderilen sağlık raporu emekliye ayrıldı. Eski dosyalar Git geçmişinde bulunabilir.

[GitHub'daki manuel Telegram bağlantı kontrolü](../../docs/telegram-antigravity.md) ayrı bir iş akışıdır.
